## US-01：查看分類最便宜商品

**As a** 裝機玩家  
**I want** 在 Dashboard 看到每個分類中最便宜的商品列表  
**So that** 我能快速掌握市場行情，找到最佳價格

### 驗收條件

| # | Given | When | Then |
|---|-------|------|------|
| AC-01 | 使用者進入 Dashboard 頁面 | 頁面載入完成 | 顯示各分類卡片，每個分類顯示前 10 名最便宜商品 |
| AC-02 | 商品列表已載入 | 檢視商品卡片 | 每張卡片顯示：商品名稱、目前價格、規格摘要 |
| AC-03 | 商品有歷史價格資料 | 檢視商品卡片 | 顯示歷史最低價 |
| AC-04 | 目前價格 = 歷史最低價 | 檢視商品卡片 | 顯示「歷史新低」徽章 |
| AC-05 | 商品已下架（status=gone） | 檢視商品卡片 | 顯示「已下架」標籤，價格灰顯 |
| AC-06 | API 載入中 | 檢視頁面 | 顯示骨架屏（skeleton loading） |
| AC-07 | API 載入失敗 | 檢視頁面 | 顯示錯誤訊息 + 重試按鈕 |

### 邊界案例
- 商品無價格（history 為空）→ 價格顯示「—」
- 分類無商品 → 顯示空狀態「暫無商品資料」

### 複雜度：M

---

## US-02：依規格分組比較商品

**As a** 比價消費者  
**I want** 將同規格商品分組比較（如 DDR5 32GB 所有商品）  
**So that** 我能精確比較同規格商品的價格差異

### 驗收條件

| # | Given | When | Then |
|---|-------|------|------|
| AC-01 | 使用者選取「記憶體」分類 | 分組載入完成 | 自動依 DDR3/DDR4/DDR5 × 容量 分組 |
| AC-02 | 分組已產生 | 檢視分組標籤 | 顯示 chips/tabs（如 [DDR5 32GB] [DDR5 16GB] [DDR4 16GB]...） |
| AC-03 | 使用者點擊特定分組（如 DDR5 32GB） | 篩選完成 | 僅顯示該分組商品，按價格低→高排序 |
| AC-04 | 分組內有多個商品 | 檢視列表 | 最便宜者標示 🥇 或綠色高亮 |
| AC-05 | 商品無規格資料（spec 為空） | 分組完成 | 歸入「其他」分組 |
| AC-06 | 分組 chips 超過 8 個 | 檢視標籤列 | 顯示「更多 ▼」折疊其餘分組 |
| AC-07 | 切換分組 | 動畫完成 | 切換時間 < 300ms，無閃爍 |

### 邊界案例
- 某分組商品數為 0 → 該分組 chip 顯示「0」或不顯示
- 商品跨分組（如同品牌不同容量） → 各歸各組，不重複

### 複雜度：L

## US-03：切換分類瀏覽

**As a** 一般瀏覽者  
**I want** 在不同分類間快速切換（CPU / 記憶體 / 顯示卡...）  
**So that** 我能一次比較多個分類的最便宜商品

### 驗收條件

| # | Given | When | Then |
|---|-------|------|------|
| AC-01 | Dashboard 頁面已載入 | 檢視頂部導覽 | 顯示分類 Tab（CPU、記憶體、顯示卡、SSD、主機板...） |
| AC-02 | 使用者點擊「記憶體」分類 Tab | 切換完成 | 記憶體分類商品列表載入，分組 chips 更新 |
| AC-03 | 使用者從「記憶體」切換到「顯示卡」 | 切換完成 | 顯示卡分類商品載入，分組 chips 更新為顯示卡分組 |
| AC-04 | 當前分類無分組資料 | 檢視頁面 | 顯示「暫無分組」提示 |

### 邊界案例
- 分類 Tab 超過 5 個 → 顯示「更多 ▼」折疊
- 切換分類時上一個分類仍在載入 → 取消上一個請求

### 複雜度：S

## US-04：查看價格走勢

**As a** 追蹤用戶  
**I want** 在商品卡片上看到價格走勢 mini chart  
**So that** 我能快速判斷價格趨勢（漲/跌/持平）

### 驗收條件

| # | Given | When | Then |
|---|-------|------|------|
| AC-01 | 商品有歷史價格資料 | 檢視商品卡片 | 顯示 mini sparkline（近 7 天或 30 天） |
| AC-02 | 價格近期下跌 | 檢視 sparkline | 線條向下，顯示綠色 |
| AC-03 | 價格近期上漲 | 檢視 sparkline | 線條向上，顯示紅色 |
| AC-04 | 價格持平 | 檢視 sparkline | 線條水平，顯示灰色 |
| AC-05 | 商品無歷史資料 | 檢視商品卡片 | 不顯示 sparkline |
| AC-06 | 使用者 hover sparkline | 檢視 tooltip | 顯示日期 + 價格 |

### 邊界案例
- 歷史資料僅 1 點 → 不顯示 sparkline
- 歷史資料跨多月 → 顯示最近 30 天

### 複雜度：M

---

## US-05：快速加入追蹤清單

**As a** 追蹤用戶  
**I want** 在商品卡片上一鍵加入追蹤清單  
**So that** 我能持續監控該商品價格變動

### 驗收條件

| # | Given | When | Then |
|---|-------|------|------|
| AC-01 | 商品未在追蹤清單 | 檢視商品卡片 | 顯示 [追蹤] 按鈕（空心愛心或 + 號） |
| AC-02 | 商品已在追蹤清單 | 檢視商品卡片 | 顯示 [已追蹤] 按鈕（實心愛心或 ✓ 號） |
| AC-03 | 使用者點擊 [追蹤] | 加入成功 | 按鈕變為 [已追蹤]，顯示 toast 通知 |
| AC-04 | 使用者點擊 [已追蹤] | 移除成功 | 按鈕變為 [追蹤]，顯示 toast 通知 |
| AC-05 | localStorage 不可用 | 點擊追蹤 | 顯示錯誤訊息「儲存空間不足」 |

### 邊界案例
- 追蹤清單已滿（>100 項） → 顯示提示「追蹤清單已滿，請先移除其他商品」

### 複雜度：S

---

## US-06：篩選與排序商品

**As a** 比價消費者  
**I want** 篩選與排序商品列表  
**So that** 我能更快找到符合需求的商品

### 驗收條件

| # | Given | When | Then |
|---|-------|------|------|
| AC-01 | 分組內有商品 | 檢視排序選項 | 顯示排序下拉選單（價格低→高 / 價格高→低 / 最近更新） |
| AC-02 | 使用者選擇「價格高→低」 | 排序完成 | 列表重新排序，最貴者在上 |
| AC-03 | 使用者輸入價格區間（$5,000-$10,000） | 篩選完成 | 僅顯示該區間商品 |
| AC-04 | 使用者勾選特定品牌 | 篩選完成 | 僅顯示該品牌商品 |
| AC-05 | 篩選結果為 0 | 檢視頁面 | 顯示「無符合商品」+ 清除篩選按鈕 |

### 邊界案例
- 價格區間下限 > 上限 → 自動交換
- 同時套用多個篩選 → 取交集

### 複雜度：M
