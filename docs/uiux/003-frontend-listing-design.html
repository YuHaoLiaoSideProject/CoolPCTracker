2. 完整畫面與狀態 Demo（Desktop ≥1024px）

側欄 240px sticky・搜尋 300ms debounce・規格篩選 AND・卡片多欄。可互動：點分類／輸入搜尋／套用與移除條件 chips／狀態列切換。

https://coolpc-tracker.github.io/CoolPCTracker/ 互動：狀態 Demo・chips 增減・主題/裝置切換
驗證重點：控制元件同高 36px、側欄 240px；空分類狀態在此僅能由狀態列觸發（demo 資料 9 分類皆有商品，對應 BDD E6）。

七個核心元件：放大渲染＋尺寸註記（實測基礎皆為本頁 CSS 計算值）。

EmptyState 空狀態三分流

沒有符合「量子電腦」的商品

搜尋範圍僅涵蓋商品名稱與規格欄位，試試其他關鍵字。

padding 48 / 16px・icon 40px・清除按鈕 36px
分流優先序：search → filter → category（keyword 有值→搜尋空；conditions 有值→篩選空；其餘→空分類）
空分類 = 純說明不報錯、不觸發重試

ErrorState 錯誤＋重試

資料載入失敗

無法取得商品資料 API（網路中斷或檔案暫時不可得）。

重試按鈕高 36px（brand 底白字）・role="alert"
fetch 失敗 →「資料載入失敗」；parse 失敗 →「資料格式錯誤」
錯誤只出現在列表區：側欄／搜尋框／篩選面板照常渲染（BDD 不白屏）

5. 狀態矩陣

八態全覆蓋：idle / hover / focus / active / disabled / loading / error / 空結果（BDD @error-handling @edge-case 24 Scenario）。

狀態視覺互動
idle卡片 surface 底＋--border 邊＋--shadow；分類項透明底；文字 --text可點擊／可輸入；卡片 cursor:pointer（004 入口預告）
hover卡片 border → --brand＋0 2px 8px rgba(31,111,235,.15)；分類項淡 --brand-soft 底；按鈕 --surface-2 底提示可操作；hover 不位移、不換行
focus:focus-visible 3px accent ring（搜尋／按鈕／chips 移除／卡片 tabindex=0）鍵盤 Enter／Space 觸發卡片 open、按鈕、chip 移除
active側欄分類 --brand-soft 底＋--brand 字＋700；狀態 Demo 按鈕白底＋accent 字aria-pressed="true"；URL 同步 ?category=<key>（mockup 更新 browser-bar URL）
disabledopacity:.5＋cursor:not-allowed無任何條件時「清除全部條件」按鈕 disabled
loading列表區 skeleton 卡片（灰階 shimmer 1.2s）；側欄／搜尋／篩選照常渲染aria-busy="true"；不白屏（BDD smoke）
error列表區 ErrorState：SVG 圖示＋「資料載入失敗／資料格式錯誤」＋brand 重試鈕重試 → loading → 重載；role="alert"；錯誤不擴散至側欄／搜尋
空結果EmptyState 三分流：搜尋（「沒有符合『xx』的商品」）／篩選（列出條件）／空分類（純說明）搜尋/篩選空 → 清除按鈕；空分類 →「查看全部商品」；皆不觸發重試
1過期橫幅：role=alert・warn 色系三件組・資料仍正常顯示（E3，>7 天與 007 共用）
2側欄 240px sticky＋9 分類筆數 badge＋deep link ?category= 雙向同步
3搜尋 300ms debounce＋clear ✕；僅比對 name＋spec（「9999」不命中歷史價）
4規格 chips AND：同欄位取代、邊界值納入（12G 命中 12G）、缺欄位靜默排除
5命中筆數「x / 14 筆」aria-live；清除全部條件保留目前分類
6卡片＝004 入口（點卡片進詳情）＋005 追蹤/比價 props 預留
7漲跌 1.4.1：顏色＋文字（漲/跌/持平/—）並存；無昨日價顯示「—」
8sparkline <2 筆不畫線顯示「—」；卡片取最近 30 點
9空狀態三分流：search→filter→category 優先序；空分類不報錯
10錯誤僅列表區：側欄／搜尋／篩選不白屏；重試不刷新全頁
11控制高度 36／44px；行動端觸控目標 44px（WCAG 2.5.5）
12圖示全 inline SVG（aria-hidden）・動畫尊重 prefers-reduced-motion
