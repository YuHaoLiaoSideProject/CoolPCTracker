# Dashboard — 篩選與排序商品（US-06）— 互動流程

> **Issue**：#22
> **User Story**：US-06
> **Parent**：#16 Dashboard
> **依賴**：#18 (US-02)

---

## 1. 功能概述

**一句話**：讓使用者篩選與排序商品列表，更快找到符合需求的商品。

---

## 2. 使用者與場景

### 2.1 使用者角色

| 角色 | 目標 |
|------|------|
| **比價消費者** | 快速找到特定價格區間或品牌的商品 |
| **裝機玩家** | 找特定品牌或價格範圍的商品 |

### 2.2 觸發入口

| 入口 | 說明 |
|------|------|
| 排序下拉選單 | 切換排序方式 |
| 價格區間篩選器 | 輸入價格範圍 |
| 品牌篩選器 | 勾選特定品牌 |

---

## 3. 操作流程圖

```mermaid
flowchart TD
    Start([商品列表已載入])
    
    Start --> ShowControls[顯示排序/篩選控制項]
    
    ShowControls --> UserAction{使用者操作}
    
    UserAction -->|切換排序| SortBy[選擇排序方式]
    UserAction -->|篩選價格| FilterPrice[輸入價格區間]
    UserAction -->|篩選品牌| FilterBrand[勾選品牌]
    UserAction -->|瀏覽商品| BrowseItems[瀏覽列表]
    
    SortBy --> ApplySort[套用排序]
    FilterPrice --> ApplyFilter[套用篩選]
    FilterBrand --> ApplyFilter
    
    ApplySort --> UpdateList[更新商品列表]
    ApplyFilter --> CheckResult{有符合商品?}
    
    CheckResult -->|是| ShowFiltered[顯示篩選結果]
    CheckResult -->|否| ShowEmpty[顯示空狀態]
    
    ShowFiltered --> ShowCount[顯示符合商品數量]
    ShowEmpty --> ClearFilter[顯示 [清除篩選] 按鈕]
    
    ClearFilter --> ResetFilter[重置所有篩選]
    ResetFilter --> UpdateList
    
    BrowseItems --> Continue[繼續瀏覽]
    
    style ShowEmpty fill:#fff8e1,stroke:#f0a000
```

## 4. 逐步互動說明

### 步驟 1：檢視排序/篩選控制項

| | 描述 |
|---|------|
| **觸發** | 商品列表載入完成 |
| **操作前** | 商品列表已顯示 |
| **系統回應** | 顯示排序下拉選單、價格區間篩選器、品牌篩選器 |
| **操作後** | 使用者可操作排序/篩選 |
| **下一步** | 步驟 2：操作排序或篩選 |

### 步驟 2：切換排序方式

| | 描述 |
|---|------|
| **觸發** | 使用者選擇排序方式（如「價格高→低」） |
| **操作前** | 目前為預設排序（價格低→高） |
| **系統回應** | 列表立即重新排序（client-side） |
| **操作後** | 最貴商品在上，最便宜在下 |
| **下一步** | 繼續瀏覽或切換其他排序 |

### 步驟 3：篩選價格區間

| | 描述 |
|---|------|
| **觸發** | 使用者輸入價格區間（如 $5,000-$10,000） |
| **操作前** | 商品列表已載入 |
| **系統回應** | 列表立即篩選，僅顯示該區間商品 |
| **操作後** | 顯示符合價格區間的商品 |
| **下一步** | 步驟 5：檢查篩選結果 |

### 步驟 4：篩選品牌

| | 描述 |
|---|------|
| **觸發** | 使用者勾選特定品牌（如「金士頓」） |
| **操作前** | 商品列表已載入 |
| **系統回應** | 列表立即篩選，僅顯示該品牌商品 |
| **操作後** | 顯示符合品牌篩選的商品 |
| **下一步** | 步驟 5：檢查篩選結果 |

### 步驟 5：檢查篩選結果

| | 描述 |
|---|------|
| **觸發** | 篩選套用完成 |
| **操作前** | 篩選條件已設定 |
| **系統回應** | 檢查是否有符合商品 |
| **操作後** | 有結果：顯示商品列表 + 數量；無結果：顯示空狀態 + 清除篩選按鈕 |
| **下一步** | 繼續瀏覽或清除篩選 |

---

## 5. 異常處理

| 情境 | 使用者看到 | 恢復路徑 |
|------|-----------|---------|
| 篩選結果為 0 | 空狀態：「無符合商品」+ [清除篩選] 按鈕 | 點擊清除篩選 |
| 價格區間下限 > 上限 | 自動交換上下限 | 無（自動處理） |
| 同時套用多個篩選 | 取交集（同時符合所有條件） | 清除部分篩選 |

---

## 6. 邊界與限制

| 項目 | 限制 | 說明 |
|------|------|------|
| 排序方式 | 3 種 | 價格低→高 / 價格高→低 / 最近更新 |
| 篩選邏輯 | 取交集 | 多個篩選條件同時套用 |
| 篩選重置 | 一鍵清除 | [清除篩選] 按鈕 |

---
